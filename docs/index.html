How it works

Three steps, no setup

Load the stylesheet once. Add a class. Tune it if you want to.

  1. Load the CSS

    From the CDN, or npm i and import it once.

    <link rel="stylesheet"
  href="https://cdn.jsdelivr.net/npm/
  @salkomdesignstudio/sds-motion-forge
  /dist/motion.min.css" />

  2. Add a class

    One class name on any element. It plays as soon as it loads.

    <h1 class="sds-velvet-drop">
  Hello
</h1>

  3. Tune it (optional)

    Modifier classes change speed, delay and looping.

    <h1 class="sds-velvet-drop
  sds-slow sds-delay-2">
  Hello
</h1>

What needs JavaScript

Most effects need none. Three things are different, and each one is optional.

CSS effects

Text, buttons, inputs, cards and loaders. Add the class and it plays.

  • 48 animate child elements
  • 29 input effects need a wrapper

Scroll effects

CSS-only in Chrome 115+ with sds-scroll-auto. Other browsers use the 1.3 KB script and data-sds.

  • Without either, the effect plays on load, not on scroll
7Needs the engine

Cursor-reactive

Magnetic Pull, Shockwave, Word Morph and four more need the 7 KB motion-interactive.min.js.

  • The engine splits the text into letters for you

Physics effects use CSS linear() (Chrome 113+, Safari 17.2+, Firefox 112+); older browsers get an approximation. Full table in the docs

Features

Built to ship, not to demo

A focused motion system for teams who want character without the weight. Everything below is checked by the build.

No JavaScript for the CSS effects
All 617 effects are plain @keyframes and classes. Two optional scripts add what CSS cannot: scroll triggering where CSS scroll-driven animation is missing (1.3 KB) and 7 cursor-reactive effects (7 KB).
617 animations
Text 117 · Buttons 100 · Inputs 100 · Cards 100 · Loaders 100 · Scroll 100, plus 7 cursor-reactive effects.
Works where a class works
Angular, React, Vue, Next.js, Bootstrap and Tailwind projects: anything that renders HTML with CSS classes.
Themeable
Set CSS variables such as --sds-primary, --sds-duration and --sds-easing to retune colour and speed.
Mostly compositor-only
468 of 617 effects animate only transform, opacity, filter or clip-path. The other 149 also animate shadows, gradients or sizes and can cost more on slow devices.
Respects reduced motion
Every animating selector is switched off under prefers-reduced-motion: reduce, and the build fails if one is missed. Every class that worked in v3 and v4 still works in v5, checked against the published package.
New in 5.1

Thirteen physics text effects

Driven by real equations, not hand-tuned curves: a spring, a bouncing ball, a pendulum, buoyancy against drag, a drag-limited gust, an infall in an inverse-square field. Each equation is sampled into a CSS linear() easing and checked against its closed-form solution on every build.

Answers

Quick answers

Short, self-contained answers to the questions developers ask most. Every number comes from the build.

What is the best CSS animation library for Angular?

There is no single best option, but a CSS-only library suits Angular because it needs no Angular-specific code. SDS Motion Forge provides 617 animations as plain CSS classes: add node_modules/@salkomdesignstudio/sds-motion-forge/dist/motion.min.css to the styles array in angular.json, then put a class such as sds-velvet-drop on any template element. No module or directive is required.

How do I add scroll animations without JavaScript?

Combine sds-scroll-auto with any sds-scroll-* class, for example class="sds-scroll-auto sds-scroll-rise". It uses native CSS scroll-driven animation (animation-timeline: view()), so no script runs in browsers that support it, such as Chrome 115+. Where it is unsupported, the optional 1.3 KB sds-scroll.min.js triggers the same effects through a data-sds attribute.

Is there an Animate.css alternative?

Yes. SDS Motion Forge is a CSS-only alternative that defines 636 @keyframes across 617 effects in six categories (text, buttons, inputs, cards, loaders, scroll), against 97 @keyframes in Animate.css 4.1.1. The trade-off is size: the full bundle is 43.7 KB gzip versus 5.2 KB, but you can import one 5.8–13.5 KB category instead.

What is the best CSS-only text animation library?

SDS Motion Forge includes 117 text animations that run from a single CSS class, for example <h1 class="sds-velvet-drop">. Five need the text split into per-character spans and a few others need child elements; each effect's page states what it needs. The text bundle can be loaded on its own at 13.5 KB gzip.

Does it respect prefers-reduced-motion?

Yes. Every animating selector is neutralized under prefers-reduced-motion: reduce, and the build fails if one is missed (npm run verify:reduced-motion). Scroll-gated elements stay visible instead of being hidden, so content is never lost for users who opt out of motion.

How big is it, and can I import only part of it?

The full bundle is 43.7 KB gzip. Each category is 5.8–13.5 KB gzip and can be imported alone, with core already included: import "@salkomdesignstudio/sds-motion-forge/categories/text";. For two or more categories, use the full bundle. The two optional scripts are 1.3 KB (scroll) and 7.0 KB (cursor effects).

Does it work with React, Vue, Next.js and Tailwind?

Yes. Import dist/motion.min.css once and use the class names with className or class in React, Next.js, Vue, Angular or a Tailwind project. Typed wrappers for React, Angular, Tailwind and Web Components exist in the repository's packages/ folder but are not yet published to npm.

Is it free to use commercially?

Yes. SDS Motion Forge is open source under the MIT license, which permits commercial use as long as the copyright and license notice stay with copies of the code. Install it with npm i @salkomdesignstudio/sds-motion-forge or load it from the jsDelivr CDN with no build step.
