How it works

Three steps. No setup.

Load the stylesheet once. Add a class. Tune it if you want to.

  1. 1

    Load the CSS

    From the CDN, or npm i and import it once.

    HTML
    <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@salkomdesignstudio/sds-motion-forge/dist/motion.min.css" />
  2. 2

    Add a class

    One class name on any element. It plays as soon as it loads.

    HTML
    <h1 class="sds-velvet-drop">
  Hello
</h1>
  3. 3

    Tune it optional

    Modifier classes change speed, delay and looping.

    HTML
    <h1 class="sds-velvet-drop sds-slow sds-delay-2">
  Hello
</h1>

Answers

Quick answers

Short, self-contained answers to the questions developers ask most. Every number comes from the build.

What is the best CSS animation library for Angular?

There is no single best option, but a CSS-only library suits Angular because it needs no Angular-specific code. SDS Motion Forge provides 417 animations as plain CSS classes: add node_modules/@salkomdesignstudio/sds-motion-forge/dist/motion.min.css to the styles array in angular.json, then put a class such as sds-velvet-drop on any template element. No module or directive is required.

How do I add scroll animations without JavaScript?

Combine sds-scroll-auto with any sds-scroll-* class, for example class="sds-scroll-auto sds-scroll-rise". It uses native CSS scroll-driven animation (animation-timeline: view()), so no script runs in browsers that support it, such as Chrome 115+. Where it is unsupported, the optional 1.3 KB sds-scroll.min.js triggers the same effects through a data-sds attribute.

Is there an Animate.css alternative?

Yes. SDS Motion Forge is a CSS-only alternative that defines 422 @keyframes across 417 effects in four categories (text, cards, loaders, scroll), against 97 @keyframes in Animate.css 4.1.1. The trade-off is size: the full bundle is 30.8 KB gzip versus 5.2 KB, but you can import one 6.2–13.7 KB category instead.

What is the best CSS-only text animation library?

SDS Motion Forge includes 117 text animations that run from a single CSS class, for example <h1 class="sds-velvet-drop">. Five need the text split into per-character spans and a few others need child elements; each effect's page states what it needs. The text bundle can be loaded on its own at 13.7 KB gzip.

Does it respect prefers-reduced-motion?

Yes. Every animating selector is neutralized under prefers-reduced-motion: reduce, and the build fails if one is missed (npm run verify:reduced-motion). Scroll-gated elements stay visible instead of being hidden, so content is never lost for users who opt out of motion.

How big is it, and can I import only part of it?

The full bundle is 30.8 KB gzip. Each category is 6.2–13.7 KB gzip and can be imported alone, with core already included: import "@salkomdesignstudio/sds-motion-forge/categories/text";. For two or more categories, use the full bundle. The two optional scripts are 1.3 KB (scroll) and 7.0 KB (cursor effects).

Does it work with React, Vue, Next.js and Tailwind?

Yes. Import dist/motion.min.css once and use the class names with className or class in React, Next.js, Vue, Angular or a Tailwind project. Typed wrappers for React, Angular, Tailwind and Web Components exist in the repository's packages/ folder but are not yet published to npm.

Does Motion Forge have an MCP server for AI tools?

Yes. @salkomdesignstudio/motion-forge-mcp lets Claude, Cursor, VS Code and other MCP clients search the 417 animations, fetch ready code and match a design's motion to the closest effect. It runs locally with npx -y @salkomdesignstudio/motion-forge-mcp, needs no account or API key, and makes no network calls.

Is it free to use commercially?

Yes. SDS Motion Forge is open source under the MIT license, which permits commercial use as long as the copyright and license notice stay with copies of the code. Install it with npm i @salkomdesignstudio/sds-motion-forge or load it from the jsDelivr CDN with no build step.
